Projet de site web pour un restaurant

Aperçu du projet

Il s'agit d'un site web de restaurant construit en utilisant HTML, CSS, JavaScript, et Bootstrap. Le site est conçu pour présenter les offres du restaurant, le menu, et permettre aux clients de faire des réservations. Le site est réactif, ce qui permet aux utilisateurs d'appareils mobiles et de bureau de bénéficier d'une expérience optimisée.

Technologies utilisées

HTML : Langage de balisage pour structurer le contenu du site web.

CSS : Style du site web pour assurer un design propre et moderne.

JavaScript : Ajoute de l'interactivité, comme la validation de formulaire et le chargement de contenu dynamique.

Bootstrap : Un cadre CSS qui garantit que le site est réactif et adapté à la mobilité.

Caractéristiques

Conception réactive : Veille à ce que le site web s'adapte à différentes tailles d'écran grâce au système de grille de Bootstrap.

Navigation interactive : JavaScript est utilisé pour rendre la barre de navigation dynamique.

Menu du restaurant : Affiche le menu du restaurant dans une disposition en grille, ce qui facilite la navigation.

Formulaire de réservation : Un formulaire fonctionnel permettant aux clients de réserver.

Galerie de photos : Présentez des images de l'ambiance et des plats du restaurant.

Section contact : Comprend l'adresse, le numéro de téléphone et l'intégration de Google Maps.
